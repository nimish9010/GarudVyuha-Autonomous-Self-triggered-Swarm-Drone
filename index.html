Mission Context

The Problem & Our Objectives

Why existing UAV systems fall short in communication-denied tactical environments — and how GarudVyuha solves it.

⚠️

Single Point of Failure

Conventional UAVs depend on a central ground control station or mothership. In contested environments, this dependency is highly susceptible to jamming, signal loss, or system breakdown — crippling the entire mission.

🎯

Objective 1: Self-Triggering Activation

Onboard MPU6050 IMU detects free-fall and immediately activates motors and flight stabilization routines mid-air — guaranteeing mission commencement without human intervention.

📡

Communication-Denied Zones

Current swarm implementations require pre-programmed or human-triggered launch sequences. In electronic warfare environments or disaster zones, external commands fail — leaving drones inoperable.

🔗

Objective 2: Decentralized Coordination

Peer-to-peer LoRa/ESP-NOW communication enables autonomous formation maintenance, collaborative search patterns, and real-time data sharing without ground dependency.

🕐

Human Operator Bottleneck

Managing multiple drones simultaneously in time-sensitive tactical missions exceeds human cognitive bandwidth. Delayed responses and missed targets compromise mission-critical outcomes.

🛡️

Objective 3: Fault-Tolerant Architecture

Distributed control ensures mission continuity even if the mothership or primary command link is lost. Individual child drones independently sustain engagement and complete objectives.

System Design

Multi-Layer System Architecture

A modular, layered architecture designed for autonomous activation, real-time swarm coordination, and onboard target detection.

01
Command Layer — Ground Control Station
GCS Interface

The Ground Control Station provides access to real-time telemetry, live FPV video downlinks, and historical mission data via a web platform. Operators define mission parameters, search boundaries, and target profiles before deployment.

Mission Planner Telemetry Dashboard Live FPV Feed Target Database
02
Communication Layer — LoRa Mesh Network
Peer-to-Peer

The LoRa SX1278 mesh network enables decentralized drone-to-drone communication. Drones share position vectors (xi, yi), search progress, and local sensor data — implementing swarm intelligence algorithms like Ant Colony Optimization for coordinated search.

LoRa SX1278 ESP-NOW Mesh Topology Digital Pheromones
03
Deployment Layer — Mothership + Child Drones
Self-Trigger

The Mothership (Arduino Uno) manages latch control and signal monitoring. Upon signal loss or altitude trigger, the MG995 servo-driven latch releases child drones. Each child's MPU6050 IMU detects free-fall and activates motors mid-air within 0.42 seconds.

Arduino Uno MPU6050 IMU MG995 Servo Latch Pixhawk 2.4.8
04
Mission Execution — Edge AI + Swarm Intelligence
YOLOv5

Onboard ESP32-CAM captures real-time video processed by YOLOv5 for target detection and classification of vehicles, persons, and weapons. When confidence exceeds the threshold (C ≥ Cthreshold), target information is broadcast to the swarm for consensus-based action.

YOLOv5 OpenCV ESP32-CAM PID Controller Edge Processing
⚡ Core Innovation — Self-Trigger Activation Logic
anet = √(ax² + ay² + az²)
Free-fall triggered when: anet ≤ θf  where  θf ≈ 0.3g
The MPU6050 IMU continuously monitors net acceleration. When the measured acceleration drops below the free-fall threshold (≈ 0.3g), the system autonomously activates motors and PID stabilization — achieving a 0.42s activation delay and 1.9s full stabilization.
Operational Flow

How GarudVyuha Works

From autonomous mid-air deployment to coordinated swarm reconnaissance — step by step.

🪂
Step 01

Self-Trigger Activation

The mothership releases child drones via servo-driven latch. Each drone's MPU6050 IMU detects free-fall (anet ≤ 0.3g) and immediately spins up brushless motors, activating flight control within 0.42 seconds — zero human intervention required.

⚖️
Step 02

PID Stabilization

The Pixhawk 2.4.8 flight controller's PID algorithm rapidly minimizes the error between desired and actual orientation angles, achieving full flight stabilization within 1.9 seconds of activation — even from a 20m+ drop altitude.

👁️
Step 03

AI Vision — Target Detection

The ESP32-CAM captures real-time FPV video processed by the onboard YOLOv5 model. Targets (vehicles, persons, weapons) are detected, classified, and localized with 93% accuracy and sub-120ms latency per frame.

📡
Step 04

Swarm Coordination via LoRa Mesh

Upon detection, target data and position vectors are broadcast across the LoRa mesh network. Peer drones share observations, coordinate search patterns using digital pheromones, and maintain safe formation spacing through real-time data exchange.

🧠
Step 05

Consensus Decision & Action

The swarm validates targets through multi-drone consensus. If confirmed — drones execute coordinated action: hover for surveillance, simulate engagement, or adjust formation. No consensus triggers continued search patterns.

🏠
Step 06

Safe Return to Base

Continuous battery monitoring triggers automatic Return-to-Base (RTB) or auto-landing when levels drop below 20%. GPS-guided navigation ensures safe recovery of all swarm units.

Key Features

Six defining capabilities that make GarudVyuha a mission-ready autonomous swarm system.

🪂

Self-Triggering Mid-Air

IMU-based free-fall detection activates motors and stabilization autonomously within 0.42 seconds — no human command needed.

🔗

Decentralized Swarm

LoRa mesh network enables peer-to-peer coordination, formation control, and collaborative search without ground dependency.

🛡️

Fault-Tolerant Design

Distributed control ensures mission continuity. If the mothership or any drone is lost, the swarm reconfigures and continues.

👁️

Real-Time AI Detection

YOLOv5 + OpenCV provides 93% accuracy target detection of vehicles, persons, and weapons with sub-120ms latency.

📡

Mesh Communication

LoRa SX1278 enables long-range, low-power peer-to-peer data sharing even in jamming or signal-denied environments.

Cost-Efficient & Scalable

Built with affordable components (Arduino, MPU6050, ESP32-CAM). Total system cost ₹31,000 — scalable to large swarms.
